SWAW Kit：项目目录绑定的便携开发与项目控制入口。

命令目录就是命令地址；每个可执行命令目录必须且只能包含一个受支持的 run.*。
以下列表由 Proj Core 扫描真实命令目录动态生成，不维护独立 catalog。

命令可提供私有 _guard/run.exe、run.ps1 或 run.cmd 声明执行前提。
Core 固定按 _global → 命令 _guard → 命令 run.* 执行；Guard 不接收动态参数，
只负责放行或拒绝，不能替后续进程注入环境。需要受管工具的 run.* 必须自行
加载并复核环境；不依赖开发环境的命令无需承担这套策略。

极薄 EXE Launcher 负责入口身份、Host/CLI 分流和原生 argv 边界；
每个项目入口都是同一模板的独立副本：共享 Core 缺失时调用 Bootstrap，
随后把参数原样交给 Rust；入口自身不声明项目配置，也不承担公开命令路由。
根 swawkit.exe 和 Launcher 模板是随仓库发布的必备制品；需要从源码生成候选时，
直接运行 _lib\proj\build.ps1，它会准备固定 Bootstrap 工具链并构建 App 与 Launcher
候选；只写入 data/proj_cache/bootstrap/build，不替换任何发布制品。

以两个点开头的地址属于 Rust Control Plane，例如 {{COMMAND}} ..entry、
{{COMMAND}} ..entry.claim 与 {{COMMAND}} ..web；它们管理 Entry 自身生命周期，
不属于 Kernel 命令，也不执行项目 Guard。
