查询命令的持久运行记录，或在资源管理器中打开一次运行的日志目录。

用法:
  {{INVOCATION}} <command-address>
  {{INVOCATION}} <command-address> --latest <n|n..m>
  {{INVOCATION}} <command-address> --run <run-id> [--after <cursor>]
  {{INVOCATION}} <command-address> --open <run-id>

命令地址使用正常 CLI 地址，例如 `.dev.status` 或 `proj.build.app`。只有来源有歧义时，
才需要写成 `kernel/.dev.status` 或 `action/proj.build.app`。

不带操作参数时输出按时间倒序排列的 JSON 清单，`latest: 1` 表示最近一次运行。
`--latest 1..3` 在同一次读取中输出最近三次运行，适合人工查询；Agent 应优先保存并使用
稳定的 run ID，再通过 `--run` 和 `--after` 增量读取。
