Query persistent command runs or open the log directory for one run.

Usage:
  {{INVOCATION}}
  {{INVOCATION}} --json [<command-locator>]
  {{INVOCATION}} --run <run-id> [--after <cursor>]
  {{INVOCATION}} --open <run-id>
  {{INVOCATION}} <command-address>
  {{INVOCATION}} <command-address> --latest <n|n..m>
  {{INVOCATION}} <command-address> --run <run-id> [--after <cursor>]
  {{INVOCATION}} <command-address> --open <run-id>

Without arguments, the command lists recent persisted runs across all commands. `--json` without a locator resolves the global `.runs` `all` collection. With a locator it resolves the selected command's Runs Facet; both forms return the same `::run/<run-id>` identities. Use a normal CLI address such as `.dev.status` or `proj.build.app` for a command-scoped query. `kernel/.dev.status` and `action/proj.build.app` are exact locator forms for protocol callers such as Facets; ordinary CLI use does not need them for disambiguation. Kernel and Action addresses are lexically separated by a leading dot (or dash) versus no leading punctuation, so an omitted Kernel dot is not corrected automatically. Agents should retain stable run IDs and read them incrementally with `--run` and `--after`.
