Query persisted command runs or open one run's journal directory in File Explorer.

Usage:
  {{INVOCATION}} <source/address>
  {{INVOCATION}} <source/address> --run <run-id> [--after <cursor>]
  {{INVOCATION}} <source/address> --open <run-id>

The command locator includes both the Catalog source and address, for example:
  kernel/.dev.status
  action/proj.build.app

Without an operation, the command returns recent runs as JSON. --run returns one run and
its events as JSON. --open accepts only a validated run ID and opens its `_runs/<run-id>/`
directory.
