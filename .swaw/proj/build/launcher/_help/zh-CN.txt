使用 Bootstrap 固定工具链构建 Proj 原生 Launcher 模板。

用法:
  {{INVOCATION}}

没有可用 Entry 时，也可以从源码树直接运行：
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File _lib\proj\build.ps1

输出:
  data/proj_cache/bootstrap/build/launcher/release/template.proj1.exe

构建入口直接准备 Bootstrap 固定的 Rust/MSVC 工具链，不依赖根 swawkit.exe、
现有 Launcher 模板、项目 Profile 或系统 PATH 中碰巧存在的编译器；
它只写构建候选，绝不修改 Favorites/template.proj1.exe 或根 swawkit.exe。

模板可在 SWAWKIT_HOME 根目录或其一级目录（如 Favorites）内复制并改名。无参数
启动 Host、托盘和本地 Web 控制台；带参数时同步执行 Rust CLI，保留原生参数边界
并返回真实退出码。移出上述范围后会拒绝启动，避免记录绝对路径。

该 Action 不接受动态参数。Launcher 编译和候选原子落盘只有这一条组件主路径。
