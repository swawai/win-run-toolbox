# RDP client entry

One entry command represents one remote account and one generated .rdp file. Start by copying and editing Favorites\template.rdp1.cmd.

# Connect and inspect sessions:
  {{COMMAND}}                          Generate or reuse the RDP file and start Remote Desktop
  {{COMMAND}} .<session-id>            Reconnect an existing user session through ordinary RDP (for example, .2)
  {{COMMAND}} .list                   List interactive peer sessions, including an empty console and lock state
  {{COMMAND}} .rdp create             Generate only; refuse to overwrite an existing target
  {{COMMAND}} .rdp create --force     Generate and overwrite an existing target

Session selectors require the selected session to belong to this entry's account. Ordinary mstsc has no session-ID argument, so selection also requires exactly one session for that account and fSingleSessionPerUser=1.

# Help:
  {{COMMAND}} .help en                Show English help
  {{COMMAND}} .help zh                Show Chinese help

# Shadow:
  {{COMMAND}} .shadow doctor                    Check Shadow prerequisites from this client to the peer
  {{COMMAND}} .shadow console                   Discover and view the active peer console user session
  {{COMMAND}} .shadow <session-id>              View a session; request target-user consent by default
  {{COMMAND}} .shadow <session-id> --control    View and control the target keyboard and mouse
  {{COMMAND}} .shadow <session-id> --no-consent Request no-consent viewing; can be combined with --control
  console accepts the same --control and --no-consent options and does not move the target session away from its console terminal.

# Manage peer Shadow through SSH:
  {{COMMAND}} .peer shadow status               Show peer Shadow state and restorable tool changes
  {{COMMAND}} .peer shadow enable               Enable peer network prerequisites for cross-host Shadow
  {{COMMAND}} .peer shadow enable --dry-run     Show the enable change plan
  {{COMMAND}} .peer shadow mode <0-4>           Set the peer's machine-wide Shadow mode
  {{COMMAND}} .peer shadow mode <0-4> --dry-run Show the mode change plan
  {{COMMAND}} .peer shadow restore              Restore peer Shadow settings changed by this tool
  {{COMMAND}} .peer shadow restore --dry-run    Show the restore change plan
  Modes: 0=disabled; 1=control with consent; 2=control without consent; 3=view with consent; 4=view without consent

# Manage and invoke peer PsExec through SSH:
  {{COMMAND}} .peer psexec status               Show managed PsExec for the peer SSH account
  {{COMMAND}} .peer psexec add                  Download, verify, and add the native PsExec binary
  {{COMMAND}} .peer psexec add --dry-run        Show the add change plan
  {{COMMAND}} .peer psexec remove               Remove the PsExec files managed by this tool
  {{COMMAND}} .peer psexec remove --dry-run     Show the remove change plan
  {{COMMAND}} .peer psexec <session-id> <program-and-args...>  Start as that session's logged-on user
  {{COMMAND}} .peer psexec -- <native-args...>  Invoke peer PsExec; adds -accepteula automatically
  PsExec keeps the SSH account's EULA record; remove only deletes the managed files

# Manage aliases through the system hosts file:
  {{COMMAND}} .hosts status            Show this entry's managed hosts alias
  {{COMMAND}} .hosts install           Non-interactive install or repair; fail if elevation is required
  {{COMMAND}} .hosts install --uac     Install or repair; prompt for UAC only when required
  {{COMMAND}} .hosts remove            Non-interactive removal; fail if elevation is required
  {{COMMAND}} .hosts remove --uac      Remove this entry's mapping; prompt for UAC only when required
  {{COMMAND}} .hosts cleanup --dry-run Show removable orphan mappings without changing hosts
  {{COMMAND}} .hosts cleanup           Non-interactive orphan cleanup; fail if elevation is required
  {{COMMAND}} .hosts cleanup --uac     Clean orphan mappings; prompt for UAC only when required

# Manage .rdp file self-signing:
  {{COMMAND}} .sign status             Show My, Root, and mstsc trust-policy state
  {{COMMAND}} .sign install            Create the My private-key certificate, Root trust copy, and mstsc trust entry
  {{COMMAND}} .sign install --dry-run  List those ADD operations without changing stores or the registry
  {{COMMAND}} .sign remove             Remove the dedicated certificates and their mstsc trust entry
  {{COMMAND}} .sign open               Open Certificates - Current User
