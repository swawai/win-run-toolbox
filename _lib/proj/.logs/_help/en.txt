Query persistent command runs or open the log directory for one run.

Usage:
  {{INVOCATION}} <command-address>
  {{INVOCATION}} <command-address> --latest <n|n..m>
  {{INVOCATION}} <command-address> --run <run-id> [--after <cursor>]
  {{INVOCATION}} <command-address> --open <run-id>

Use a normal CLI address such as `.dev.status` or `proj.build.app`. Add `kernel/` or `action/` only when the source is ambiguous. Agents should retain stable run IDs and read them incrementally with `--run` and `--after`.
